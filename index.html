How It Works

Get ValVoice running in four simple steps

1

Download & Install ValVoice

Download ValVoice from the website and complete the installation.
2

Install VB-CABLE

Install the free VB-CABLE virtual audio driver so ValVoice can route voice into Valorant.

3

Launch ValVoice

Open ValVoice and let it initialize before launching Valorant.

4

Configure Valorant & Play

In Valorant, set Input Device to "CABLE Output," match your PTT key, and start playing.

Frequently Asked Questions

Find answers to common questions about ValVoice

Is ValVoice safe to use with Valorant?

Yes, ValVoice is completely safe. It doesn't touch game files or inject anything into Valorant. It operates entirely locally using screen OCR to read chat, which is a safe, non-invasive method.

Does ValVoice affect game performance?

ValVoice is lightweight and efficient. It runs quietly in your system tray alongside the game. Note that the local XTTS AI voice engine may take approximately 90-100 seconds to start on first launch.

Can I customize the voices?

Absolutely! ValVoice runs a powerful AI voice engine locally on your PC, giving you access to 30+ realistic, high-quality agent voices.

How do I install ValVoice?

Download and install ValVoice first. Then install the free VB-CABLE virtual audio driver. Launch ValVoice, open Valorant, and set your Voice Chat Input Device to "CABLE Output." Finally, match your Push-to-Talk key in ValVoice and Valorant, and you're ready to play.
