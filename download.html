What is ValVoice?

ValVoice is an independent Windows desktop application that converts in-game VALORANT text chat into spoken voice communication in real time. It uses local screen OCR (Optical Character Recognition) to detect visible text messages and synthesizes voice audio locally on your PC, routing it into your team's voice chat via a virtual audio cable.

ValVoice operates completely non-invasively without injecting code or modifying game memory, protecting player account safety.

Quick Installation Guide (4 Steps)

Step 1: Download

Download and run ValVoice-Setup.exe to install the desktop client on your Windows PC.

Step 2: VB-CABLE

Download and install the free VB-CABLE Driver as Administrator, then restart your PC.

Step 3: Launch App

Launch ValVoice and verify that audio output is routed to CABLE Input.

Step 4: Game Audio

In Valorant Settings → Audio → Voice Chat, set Input Device to CABLE Output.
